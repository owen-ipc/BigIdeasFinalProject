# BigIdeasFinalProject: Finding the Best Neighborhood in Pittsburgh

## Project Overview
This project evaluates Pittsburgh neighborhoods to determine the overall "best" neighborhood to live in by analyzing three distinct quality-of-life metrics: **public safety**, **firearm safety**, and **environmental richness**. All datasets are sourced from the City of Pittsburgh via the Western Pennsylvania Regional Data Center.
